About Me

I build software that solves real problems

Full-stack development with an eye for interface detail and a bias for shipping real products.

I’m Jishan Tamboli, a full-stack web developer focused on building products end-to-end — from responsive interfaces to server-side logic. I work primarily with React, Next.js, TypeScript and Node.js, and I care deeply about clean architecture and performance.

Recent work includes a live e-commerce storefront built with Next.js, along with business sites and web apps. Beyond the browser, I explore AI-powered tooling and workflow automation to build software that saves people time.
